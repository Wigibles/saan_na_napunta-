# SaanNaPunta showcase page

A one-page preview of the app for friends, presented by Chito. Published at
https://claude.ai/artifact/8xPdEy6x7x1ResVjU1SUfz (private until shared from the page's Share menu).

- `index.html` – the page. It was written for the Artifact host, which adds the `<!doctype html>`,
  `<head>` and `<body>` wrapper, so it has none of its own. It still opens in a browser for a quick look.
- `img/` – Chito poses (320 px, from `app/src/main/res/drawable`) and screenshots from the Preview build.
- `sfx/` – the app's UI sounds (from `app/src/main/res/raw`).

The "Try Chito" playground copies Chito's lines and rules from `ui/chito/ChitoLines.kt`; update both together.
